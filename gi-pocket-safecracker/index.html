Designer สร้างหน้าตา • Blocks สร้างการทำงาน
บล็อก when…do คือ “เมื่อเกิดเหตุการณ์ ให้ทำ…” ช่องต่อด้านในรับคำสั่ง ส่วนช่องค่ารับตัวเลข ข้อความ หรือ true/false

ลองแรก: ใส่ set StartButton.Text to แล้วเสียบบล็อกข้อความจาก Text เป็น HELLO กดปุ่มบน Companion ดูข้อความเปลี่ยน จากนั้นลบเฉพาะคำสั่งทดลองนี้ ตั้ง Text กลับ START แล้วใช้ event เดิมสร้างเกมต่อ ไม่เพิ่ม Click ซ้ำ

หาบล็อกที่ไหน: Variables → initialize global / get • Math → ตัวเลข + − ≥ ≤ • Logic → and / true / false • Control → if then (กดเฟืองเพิ่ม else) • คลิกชื่อ Component → event / set / get / call

รู้จักตำแหน่งก่อนวาดเส้น

X คือระยะจากซ้าย ส่วน Y คือระยะจากบน จุดกลางจออยู่ x=150 ตั้งตัวแปร halfWidth=24 เพื่อเก็บ “ครึ่งความกว้างช่อง” ขอบซ้ายจึงเป็น 150−24=126 และขอบขวา 150+24=174 ไม่ใช่ความกว้างทั้งช่อง

ก่อน DrawLine: สร้าง initialize global halfWidth to 24 จาก Variables และ Math ก่อน แล้วค่อยต่อ + / − กับ get global halfWidth เส้นแนวตั้งใช้ x1=x2 แต่ y1=12 และ y2=108

06ออกแบบ • เปลี่ยนทีละอย่าง

จากแบบจำลองไปยังแอปจริง

  1. ใช้คนทดสอบคนเดิม ลองค่าเริ่มต้น 2 รอบก่อนเปลี่ยน: Speed = 6, halfWidth = 24
  2. แก้ค่าเดียวใน Blocks หรือ Designer แล้วเชื่อมต่อใหม่ให้ค่าล่าสุดทำงาน
  3. กด START ตรวจว่าขอบช่องถูกวาดตรงกับค่าที่ใช้ตรวจผล
  4. ลองค่าที่เปลี่ยน 2 รอบ บันทึกทั้ง 4 ผล แล้วทดสอบขอบช่องและ STOP ซ้ำอีกครั้ง

ผลจริง 2 รอบก่อน + 2 รอบหลัง

OPEN/LOCKED เป็นข้อมูลสั้น ๆ ไม่ใช่ข้อพิสูจน์ความยากกับทุกคน

เลือกสีได้เพิ่ม แต่หลักฐานการออกแบบวันนี้คือการเปลี่ยนความเร็วหรือความกว้างและอธิบายผล

จะเทียบผลแพ้ชนะของสองคน ต้องใช้แอปเวอร์ชันเดียวกันบนเครื่องเดียวกัน ไม่เทียบคนละความยาก

07เล่นจริง • ทดสอบกับเพื่อน

ผลัดกันลอง
ใช้กติกาเดียวกัน

  1. เลือกแอปของคู่หนึ่งเวอร์ชัน ใช้มือถือเครื่องเดียวกัน ตั้งค่าเหมือนกันตลอดการแข่งขัน
  2. ให้ทั้งคู่ซ้อมคนละ 1 รอบก่อนนับผล ไม่เปลี่ยนค่าระหว่างรอบ
  3. ซ้อมคนละ 1 ครั้ง แล้วเล่น A1 → B1 เป็นงานหลัก รอบ A2/B2/A3/B3 เป็นกิจกรรมเพิ่มเมื่อเวลาเหลือ
  4. จด OPEN หรือ LOCKED หากแอปค้างหรือมีการรบกวน ให้รอบนั้นเริ่มใหม่ทั้งคู่โดยไม่เปลี่ยนกติกา
เปรียบเทียบจำนวนครั้งที่เปิดได้เพื่อความสนุก หากเท่ากันถือว่าเสมอ คะแนนเกมไม่ใช่คะแนนความเข้าใจโค้ด

หลังเล่น ให้เพื่อนชี้เหตุการณ์หยุด และให้เจ้าของอธิบายว่าตรวจตำแหน่งอย่างไร
