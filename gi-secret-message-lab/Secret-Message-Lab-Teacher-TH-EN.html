เลือกตัวเลขด้วยปุ่มลูกศร หรือแตะช่องอักขระในโหมด index • ไม่มีเสียง ไม่มีตัวจับเวลา

ลงมือเอง • การออกแบบของเราเปลี่ยนโค้ด

สร้างคำสั่งใหม่ให้เพื่อน

  1. คิดคำสั่งสมมติใหม่ เลือก A–Z, 0–9 และช่องว่าง
  2. ใส่ตัวรบกวนหน้าและหลัง ด้านละ 1–3 ตัว รวมทั้งหมดไม่เกิน 24 ตัว
  3. เขียน my_message, my_start, my_stop และนิพจน์ของ my_order ในไฟล์ตนเอง
  4. สร้างคำใบ้: ข้ามตัวรบกวนกี่ตัว และเก็บคำสั่งกี่ตัว รวมช่องว่าง
my_message = "..."
my_start = ...
my_stop = ...
my_order = ...

ห้ามคัดลอกคำสั่งตัวอย่าง เปลี่ยนข้อความและจำนวนตัวรบกวนให้ค่าขอบเปลี่ยนจริง

ครูลดความช่วยเหลือ

ถามว่า “ตัวแรกที่ต้องเก็บอยู่ช่องไหน?” ก่อนบอกตัวเลข

ชี้หรือนับด้วยบัตรได้ แต่ผู้เรียนต้องเลือกขอบและเขียนนิพจน์เอง

หน้านี้ไม่มีเฉลยงานอิสระ

เก็บหลักฐานว่าใครเขียน ใครอธิบาย และได้รับความช่วยเหลือแบบใด

คาดการณ์ → รัน → เปรียบเทียบ → แก้ไข

รันได้ ยังต้องตรวจว่าถูก

  1. ตรงตามเป้า: คาดการณ์คำสั่งก่อน Run แล้วเทียบทุกตัว รวมช่องว่าง
  2. ขาดหนึ่งตัว: ลด stop ลง 1 คาดการณ์ตัวที่หาย แล้วรัน แก้กลับ และรันซ้ำ
  3. เสริมสำหรับผู้เสร็จก่อน: ทดลอง start เท่ากับ stop ในสำเนาหรือกระดานครู สังเกตข้อความว่าง
  4. หลังเปลี่ยนโจทย์: เพิ่มตัวรบกวนหน้าหนึ่งตัว (ครั้งนี้ยอมให้ด้านหน้า 2–4 ตัว รวมไม่เกิน 25 ตัว) ต้องเลื่อนขอบใดบ้าง? คาดการณ์แล้วทดสอบ คำสั่งต้องเหมือนเดิม บันทึกเวอร์ชันใหม่ แล้วให้เพื่อนลองโจทย์ฉบับแก้อีกครั้งอย่างรวดเร็ว

จดผลที่เห็นจริง ไม่ใช่แค่ผลที่คาด

ช่วยแก้ทีละจุด

  • IndexError: มี index นี้จริงไหม?
  • SyntaxError: ตรวจเครื่องหมายคำพูด วงเล็บ และ :
  • คำสั่งขาดท้าย: stop หยุดก่อนช่องใด?

ขอบ slice อาจเท่าความยาวข้อความได้ แต่ index ต้องอยู่ก่อนขอบนั้น ในบทนี้ใช้ค่าที่ไม่ติดลบและไม่มี step

เพื่อนได้ใช้จริง • บันทึกผลงานไว้

แลกโจทย์ แล้วอธิบายโค้ด

  1. บันทึกไฟล์ก่อน ให้เพื่อนดูเฉพาะกรอบ SHARE ONLY ด้านบนของใบงานหน้า 2: packet จำนวนตัวรบกวนด้านหน้า และความยาวคำสั่ง ใช้กระดาษปิดทุกส่วนใต้กรอบ และซ่อนหน้าจอ/ผลลัพธ์จนเพื่อนคาดการณ์เสร็จ
  2. เพื่อนคาดการณ์ start/stop ผู้สร้างจดค่าที่เพื่อนเสนอ ใส่ค่าในโค้ด แล้ว Run และเปิดผลลัพธ์
  3. ผู้เล่นอธิบายว่า “เก็บตั้งแต่… และหยุดก่อน…” แล้วสลับบทบาท
  4. แก้จากคำแนะนำ รันตรวจซ้ำ บันทึก และเปิดไฟล์ที่บันทึกแล้วอีกครั้ง
