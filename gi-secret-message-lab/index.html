INDEPENDENT • YOUR DESIGN CHANGES THE CODE

สร้างคำสั่งใหม่ให้เพื่อนBuild an original mission for a friend.

  1. คิดคำสั่งสมมติใหม่ เลือก A–Z, 0–9 และช่องว่างInvent a new fictional command using A–Z, 0–9 and spaces.
  2. ใส่ตัวรบกวนหน้าและหลัง ด้านละ 1–3 ตัว รวมทั้งหมดไม่เกิน 24 ตัวAdd 1–3 noise characters on each side. Maximum packet length: 24.
  3. เขียน my_message, my_start, my_stop และนิพจน์ของ my_order ในไฟล์ตนเองAuthor your packet, boundaries and my_order expression in your own file.

PREDICT → RUN → COMPARE → REPAIR

รันได้ ยังต้องตรวจว่าถูกRunning is not the same as being correct.

  1. ตรงตามเป้า / Correct command: คาดการณ์คำสั่งก่อน Run แล้วเทียบทุกตัว รวมช่องว่างPredict the command before running. Compare every character, including spaces.
  2. ขาดหนึ่งตัว / One too short: ลด stop ลง 1 คาดการณ์ตัวที่หาย แล้วรัน แก้กลับ และรันซ้ำReduce stop by one. Predict the missing character, run, repair the boundary, and run again.
  3. เสริมสำหรับผู้เสร็จก่อน / Optional early-finisher: ทดลอง start เท่ากับ stop ในสำเนาหรือกระดานครู สังเกตข้อความว่างIn a copy or on the teacher board, set start equal to stop. Observe the empty string. This is optional.
  4. หลังเปลี่ยนโจทย์ / After redesign: เพิ่มตัวรบกวนหน้าหนึ่งตัว (ครั้งนี้ยอมให้ด้านหน้า 2–4 ตัว รวมไม่เกิน 25 ตัว) ต้องเลื่อนขอบใดบ้าง? คาดการณ์แล้วทดสอบ คำสั่งต้องเหมือนเดิม บันทึกเวอร์ชันใหม่ แล้วให้เพื่อนลองโจทย์ฉบับแก้อีกครั้งอย่างรวดเร็ว
    Add one front noise character; the revised packet may have 2–4 in front and 25 total. Predict both new boundaries. Run and verify the command is unchanged. Have the peer quickly retest the revised mission.

จดผลที่เห็นจริง ไม่ใช่แค่ผลที่คาด / Record observed output, not only the prediction.

ช่วยแก้ทีละจุดDebug one thing at a time

  • IndexError: มี index นี้จริงไหม?Is that index inside the string?
  • SyntaxError: ตรวจเครื่องหมายคำพูด วงเล็บ และ :Check quotes, brackets, and the colon.
  • คำสั่งขาดท้าย: stop หยุดก่อนช่องใด?Which character does stop exclude?

ขอบ slice อาจเท่าความยาวข้อความได้ แต่ index ต้องอยู่ก่อนขอบนั้น ในบทนี้ใช้ค่าที่ไม่ติดลบและไม่มี stepA slice may stop at the string length. An index must be smaller. This lesson uses nonnegative values and no step.
